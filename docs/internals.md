# Lanzou++ 实现说明

> 这里存放从 `lanzou-plus.user.js` 移出的中文注释。代码里只保留少量必要的英文短注释；站点行为、实测数据和历史原因集中在这里。

## 概览

- **下载路径**：Firefox 走隐藏 iframe；Chromium 走单个顶层窗口，整批结束后自动关闭。
- **自动加载**：进入文件夹后自动翻完所有分页，按站点回执和行数双判据处理限流、末页。
- **直链**：下载前解析文件页，短时间复用；失败项可重试。
- **搜索**：精确子串 + 字符顺序模糊匹配。
- **队列**：串行发起下载，支持停止、失败重试和状态行。
- **密码页**：统一处理密码框和回车提交。
